ToonStory AI
Turn a short children's story into colorful cartoon scenes and a simple animated video.
Files
index.html — the complete browser app.
README.md — setup notes.
Use
Open the website.
Enter a Pollinations publishable (pk_) key.
Enter a short children's story.
Choose a style and 1–3 scenes.
Tap Generate My Cartoon.
Important
This version does not require a GPU server. Images are requested from the image API and the simple WebM video is assembled in the browser.
Never put a secret sk_ API key into this public file. API limits and free allowances are controlled by the provider and may change.
For GitHub Pages, keep index.html in the repository root and enable Pages from the main branch.
